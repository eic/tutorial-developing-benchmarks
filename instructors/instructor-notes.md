This tutorial builds on the earlier EIC tutorials and assumes learners already have a working
`eic-shell` and a GitHub account with membership of the EIC organization.

## Before the session

- Ask learners to complete the [Setup](../learners/setup.md) page in advance, including downloading
  the starting analysis files and one simulation-campaign file (the `xrdcp` step can be slow).
- Confirm learners can push to GitHub over SSH, since the pipeline exercises require opening pull
  requests against the benchmark repositories.

## Timing

Each of the five exercises is designed for roughly 20-30 minutes. The GitLab CI pipelines can take a
while to run, so plan to start a pipeline and move on while it completes rather than waiting live.
